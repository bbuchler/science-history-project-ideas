# Science + History Project Module Ideas

A small brainstorming site for cross-curricular project modules connecting science, history, technology, literacy, and SBA-style evidence work.

This is a static site:

- `index.html` is the page.
- `assets/web/` contains web-sized images used by the page.
- It can be hosted on Vercel, GitHub Pages, or any static web host.

Local preview:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:8765/index.html
```
